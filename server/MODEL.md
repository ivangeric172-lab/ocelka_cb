# Модель даних (чернетка)

Рішення з розбору моделі для «Noha NS-720». `Kategoria` і `Dopyt` ще попереду.

## Vyrobok

| Поле | Тип | `null`? | Примітка |
|---|---|---|---|
| `id` | `long` | ні | дає програма, ніколи не змінюється |
| `kod` | `String` | ні | унікальний, напр. `NS-720`; за ним шукає адмін |
| `nazov` | `String` | ні | те, що бачить клієнт: «Noha NS-720 hranatá» |
| `kategoria_id` | `long` | ні | посилання на `Kategoria.id` |
| `cena` | `Long`, центи | так | 24,10 € → `2410`; `null` = «Cena dohodou» |
| `ucel` | `String` | так | призначення |
| `material` | `enum Material` | ні | |
| `forma` | `enum Forma` | так | `null` для виробів без форми (водостік, раковина) |
| `sirka`, `hlbka`, `vyska`, `priemer`, `dlzka` | `double`, мм | за правилом 1 | |
| `dostupnost` | `enum Dostupnost` | ні | |
| `termin` | `Integer`, тижні | за правилом 2 | не від'ємний |

Не зберігаємо, а обчислюємо: «obdĺžniková» (`sirka != hlbka`), рядок розмірів «60 × 60 × 720 mm» / «Ø 60 × 720 mm».

## Enum

- `Forma`: `HRANATA`, `OKRUHLA`.
- `Dostupnost`: `NA_SKLADE`, `NA_OBJEDNAVKU`, `NIE_JE`; кожне значення має поле з текстом для сайту («Na sklade»).
- `Material`: `OCEL_1_4301`, `OCEL_1_4404`; кожне значення має поле з позначенням для штампу (`"1.4301"`).
  Нову марку додає програміст (зміна коду), не адмін.

## Правила

1. **Розміри за формою:**
   - `HRANATA` → `sirka`, `hlbka`, `vyska`; решта `null`;
   - `OKRUHLA` → `priemer`, `vyska`; решта `null`;
   - `null` → `dlzka`, `sirka`, `hlbka`; `priemer` `null`.
2. **Термін:** заповнюється лише при `NA_OBJEDNAVKU`; там `null` = «Termín dohodou». При `NA_SKLADE` і `NIE_JE` завжди `null`.
