# Ocelka server

Бекенд на Java. Пише його власник проєкту, Claude — ментор (див. `CLAUDE.md`).

## План (з `PIDSUMOK.md`)
1. Модель даних: поля для виробу, категорії й запиту. Почати з «Noha NS-720».
2. Вбудований `com.sun.net.httpserver.HttpServer`: віддає HTML-сторінки з кореня репозиторію.
3. `GET /api/vyrobky` → JSON зі списком виробів (спершу з коду, без бази).
4. SQLite замість даних у коді.
5. `POST /api/dopyt` для форми `dopyt.html` (зараз там функція-заглушка `sendDopyt`).
6. Адмін: вхід за паролем, ціна, наявність, термін; зручно з телефона.

## Безпека: що і на якому кроці
- **Завжди:** жодних паролів і ключів у коді чи в Git; сервер довіряє лише собі, а не браузеру.
- **Крок 5 (`POST /api/dopyt`):** перевірка всіх полів на сервері; ліміт запитів з однієї адреси (спам); вкладення — лише дозволені типи, до 20 МБ, власна назва файлу на диску; SQL лише через `PreparedStatement` (SQL-ін'єкції).
- **Крок 6 (адмін):** пароль зберігається як хеш (не текст); ліміт спроб входу; 2FA; лише HTTPS; резервні копії бази.

## Середовище
- JDK 25, Gradle (Kotlin DSL), IntelliJ IDEA.
- Під час розробки: `http://localhost:8080`.

Папка поки порожня: проєкт Gradle створюється на першому кроці.
