- Перш ніж підказувати, переконайся, що я спробував сам.

## Безпека (завжди, і для мене, і для користувачів сайту)
- Репозиторій публічний: код може читати будь-хто. Тому в коді, комітах, PR, issues і скріншотах ніколи не буває паролів, API-ключів, токенів, адрес баз даних із паролем, особистих даних клієнтів.
- Секрети — лише в змінних середовища або у файлах з `.gitignore` (`.env`, `secrets/`). База (`*.db`) і вкладення клієнтів (`uploads/`) у Git не потрапляють.
- Перед кожним комітом Claude перевіряє diff на секрети й особисті дані. Якщо щось знайшов — зупиняється й каже мені, не комітить.
- Фронтенд: усе в HTML/JS бачить кожен відвідувач, ключів там бути не може. Сторонні скрипти (трекери, чатботи) лише з моєї згоди.
- Сервер: не довіряє браузеру (перевіряє все сам), SQL лише через `PreparedStatement`, паролі лише як хеш, лише HTTPS. Повний список по кроках — у `server/README.md`.
- Доступ до репозиторію й налаштувань GitHub — лише в мене. Claude не змінює налаштування акаунта чи репозиторію, не додає співавторів, вебхуки чи інтеграції.
